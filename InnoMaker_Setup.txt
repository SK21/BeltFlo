BeltFlo — InnoMaker USB2CAN setup
==================================

The next BeltFlo build adds support for the InnoMaker USB2CAN adapter.
To use it:

1. Install InnoMaker's Windows driver for the USB2CAN adapter
   (from the InnoMaker website or their driver installer).

2. Download the InnoMaker USB2CAN C# SDK and copy these two files
   into the BeltFlo application folder (the folder containing
   BeltFlo.exe):

       InnoMakerUsb2CanLib.dll
       LibUsbDotNet.dll

   These are the only DLLs in the C# SDK's Lib folder — InnoMaker
   ships them 32-bit only. Download them as raw files (from the GitHub
   page use the Download button on each file, or download the whole
   repo as a zip — saving the web page itself gives a corrupt DLL).

   If the error log said "bitness does not match" or "class
   InnoMakerUsb2CanLib not found", update BeltFlo.exe to the newest
   build (2026-07-06 or later) — the DLLs are fine, keep them where
   they are.

PCAN (alternative adapter)
--------------------------
   BeltFlo builds BEFORE 2026-07-06 did not support PCAN at all (the
   driver was an empty stub) — update BeltFlo.exe first. Then: install
   the PEAK device driver package from peak-system.com (it includes
   PCAN-Basic), select CAN Driver: PCAN in BeltFlo, Save & Apply,
   restart. Nothing needs to be copied into the app folder.

Checking whether the module is sending (any adapter)
----------------------------------------------------
   The module sends its data unprompted; the PC sends the conveyor
   settings back every 2 s. CAN frames need at least one ACTIVE receiver
   on the bus — if no program has the adapter open, the module's frames
   are not acknowledged. "No messages on the bus" therefore usually
   means the PC side never opened, not that the module is silent.

   To test the module independent of BeltFlo: open PCAN-View (PEAK's
   free tool) at 250 kbit/s in normal mode (NOT listen-only). A working
   module shows IDs 18FF02F8h (counters) and 18FF03F8h (status), both
   at 5 Hz. With BeltFlo running, the PC's settings appear as 18FF04F9h
   and 18FF05F9h every 2 s.

3. In BeltFlo:  Menu > Settings > Module communication
   - select CAN
   - CAN Driver: InnoMaker
   - COM Port is ignored for InnoMaker (the first adapter found is
     used), then Save & Apply and restart when prompted.

If CAN still fails to start, send the newest file from:

       Documents\BeltFlo\Logs

The exact reason (DLL missing, wrong bitness, no adapter found, etc.)
is written there.
